# Glam Boutique — Eldosya Ventures

Unisex fashion marketing site. React + Vite + Tailwind CSS + GSAP.

## Brand
- Chic Cream `#F9F8F3` (50% backgrounds)
- Onyx Black `#111111` (25% structure/type)
- Glam Red `#C41220` (15% CTAs/highlights)
- Slate Gray `#707070` / `#E5E5E5` (10% borders/muted)
- Fonts: Yellowtail (script wordmark/accents), Playfair Display (headline body), Inter (body/UI)

## Local development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
Outputs to `dist/`.

## Deploy (Netlify)
- Build command: `npm run build`
- Publish directory: `dist`
